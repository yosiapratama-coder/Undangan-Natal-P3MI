# Website Undangan Natal — P3MI GMI Imanuel Ujungbatu

Website statis, responsif, dan bisa dipublikasikan gratis. Logo sudah dipasang:
- Logo P3MI: posisi tengah-atas sebelah kiri.
- Logo GMI: posisi tengah-atas sebelah kanan.

## Menjalankan di komputer
1. Ekstrak ZIP ini.
2. Buka folder `natal_p3mi_gmi_imanuel` di Visual Studio Code.
3. Klik kanan `index.html` lalu pilih **Open with Live Server** (jika ekstensi Live Server sudah terpasang).
   Alternatif: buka `index.html` langsung di browser.

## Membuat website dapat diakses semua orang (Netlify)
1. Buka https://app.netlify.com/drop
2. Login/daftar akun Netlify.
3. Seret folder `natal_p3mi_gmi_imanuel` (bukan file ZIP) ke halaman Netlify Drop.
4. Tunggu proses selesai. Netlify akan memberikan alamat website publik berakhiran `netlify.app`.
5. Bagikan alamat tersebut atau buat QR Code dari alamat itu.

## Mengubah tulisan
Buka `index.html`, lalu ubah teks yang diperlukan. Untuk mengganti logo, timpa file di folder `assets` dengan nama yang sama (`logo-p3mi.jpg` dan `logo-gmi.png`).
